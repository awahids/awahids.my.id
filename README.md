# Portfolio (Next.js)

This is a refactor of the personal portfolio using Next.js 15, TypeScript and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Lint & Test

```bash
npm run lint
npm test
```

Content placeholders are stored in `data/site.ts`. Replace the template values (`{{ }}`) with your information.
