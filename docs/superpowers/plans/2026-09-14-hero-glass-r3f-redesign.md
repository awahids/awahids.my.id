# Hero Glass + r3f/drei Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the homepage Hero a new glass-styled 3D scene (built with `@react-three/fiber`/`@react-three/drei`) it doesn't currently have, re-skin its content panel as frosted glass, and migrate the existing AI Lab hero's raw-`three.js` icosahedron to the same r3f/drei stack while preserving its current bold/lime visual behavior exactly.

**Architecture:** Two `react-three-fiber` `<Canvas>` scenes replace/introduce declarative 3D: a new `HeroGlassScene` (homepage, new `GlassBlob` using drei's `MeshDistortMaterial` + `Environment`) and a rewritten `GenerativeArtScene` (AI Lab, same custom GLSL shader as today, just declarative). Both are wrapped in a shared `WebglErrorBoundary` so a 3D failure never takes down the surrounding text content. `Hero.jsx`'s existing Supabase-fetch/GSAP/Framer-Motion logic is untouched; only CSS changes give it the glass look.

**Tech Stack:** React 18, `three` (existing, `^0.160.0`), new: `@react-three/fiber`, `@react-three/drei`. No new test framework (project has none; verification is `npm run lint`, `npm run build`, and manual browser checks).

## Global Constraints

- Scope is Hero only (homepage `Hero.jsx` + `/ai-lab`'s `AnomalousMatterHero`) — do not touch `Portfolio.jsx`, `PortfolioScrollSwap.jsx`, `SkillsScene.jsx`, `SkillsRelay.jsx`.
- No new global design-token system — reuse existing CSS custom properties in `src/index.css` (`--lime`, `--dark`, `--stroke-soft`, `--radius-lg`, etc.), add new ones only if genuinely needed.
- AI Lab's icosahedron keeps its current bold/lime generative-noise look and interaction (mouse-driven point light, same shader) — this is a technical migration to r3f, not a restyle.
- Homepage Hero's 3D scene is new (glass/distort look), replacing nothing.
- `Hero.jsx`'s Supabase fetch, GSAP kinetic-word effects, and Framer Motion variants must not change behaviorally — only CSS classes on existing elements change.
- `prefers-reduced-motion` must disable rotation/animation in both 3D scenes, matching how `Hero.jsx` already gates its own GSAP effects.
- No automated test framework is introduced. Every task's verification step is `npm run lint`, `npm run build`, and a manual dev-server check.

### Task 2: Add a shared `WebglErrorBoundary` component

**Files:**
- Create: `src/components/WebglErrorBoundary.jsx`

**Interfaces:**
- Produces: `WebglErrorBoundary` (default export), a React class component accepting `children` and an optional `fallback` prop (React node, defaults to `null`). Renders `children` normally; if a descendant throws during render, renders `fallback` instead and logs the error via `console.error`. Used by Task 3 (AI Lab scene) and Task 4 (homepage scene) to wrap their `<Canvas>` trees.

- [ ] **Step 1: Create the component**

```jsx
import React from 'react';

class WebglErrorBoundary extends React.Component {
  constructor(props) {
    super(props);
    this.state = { hasError: false };
  }

  static getDerivedStateFromError() {
    return { hasError: true };
  }

  componentDidCatch(error) {
    console.error('3D scene failed to render:', error);
  }

  render() {
    if (this.state.hasError) {
      return this.props.fallback ?? null;
    }
    return this.props.children;
  }
}

export default WebglErrorBoundary;
```

```jsx
const vertexShader = `
  uniform float time;
  varying vec3 vNormal;
  varying vec3 vPosition;

  vec3 mod289(vec3 x) { return x - floor(x * (1.0 / 289.0)) * 289.0; }
  vec4 mod289(vec4 x) { return x - floor(x * (1.0 / 289.0)) * 289.0; }
  vec4 permute(vec4 x) { return mod289(((x*34.0)+1.0)*x); }
  vec4 taylorInvSqrt(vec4 r) { return 1.79284291400159 - 0.85373472095314 * r; }

  float snoise(vec3 v) {
      const vec2 C = vec2(1.0/6.0, 1.0/3.0);
      const vec4 D = vec4(0.0, 0.5, 1.0, 2.0);
      vec3 i  = floor(v + dot(v, C.yyy) );
      vec3 x0 = v - i + dot(i, C.xxx) ;
      vec3 g = step(x0.yzx, x0.xyz);
      vec3 l = 1.0 - g;
      vec3 i1 = min( g.xyz, l.zxy );
      vec3 i2 = max( g.xyz, l.zxy );
      vec3 x1 = x0 - i1 + C.xxx;
      vec3 x2 = x0 - i2 + C.yyy;
      vec3 x3 = x0 - D.yyy;
      i = mod289(i);
      vec4 p = permute( permute( permute(
                  i.z + vec4(0.0, i1.z, i2.z, 1.0 ))
                + i.y + vec4(0.0, i1.y, i2.y, 1.0 ))
                + i.x + vec4(0.0, i1.x, i2.x, 1.0 ));
      float n_ = 0.142857142857;
      vec3  ns = n_ * D.wyz - D.xzx;
      vec4 j = p - 49.0 * floor(p * ns.z * ns.z);
      vec4 x_ = floor(j * ns.z);
      vec4 y_ = floor(j - 7.0 * x_ );
      vec4 x = x_ * ns.x + ns.yyyy;
      vec4 y = y_ * ns.x + ns.yyyy;
      vec4 h = 1.0 - abs(x) - abs(y);
      vec4 b0 = vec4( x.xy, y.xy );
      vec4 b1 = vec4( x.zw, y.zw );
      vec4 s0 = floor(b0)*2.0 + 1.0;
      vec4 s1 = floor(b1)*2.0 + 1.0;
      vec4 sh = -step(h, vec4(0.0));
      vec4 a0 = b0.xzyw + s0.xzyw*sh.xxyy ;
      vec4 a1 = b1.xzyw + s1.xzyw*sh.zzww ;
      vec3 p0 = vec3(a0.xy,h.x);
      vec3 p1 = vec3(a0.zw,h.y);
      vec3 p2 = vec3(a1.xy,h.z);
      vec3 p3 = vec3(a1.zw,h.w);
      vec4 norm = taylorInvSqrt(vec4(dot(p0,p0), dot(p1,p1), dot(p2, p2), dot(p3,p3)));
      p0 *= norm.x;
      p1 *= norm.y;
      p2 *= norm.z;
      p3 *= norm.w;
      vec4 m = max(0.6 - vec4(dot(x0,x0), dot(x1,x1), dot(x2,x2), dot(x3,x3)), 0.0);
      m = m * m;
      return 42.0 * dot( m*m, vec4( dot(p0,x0), dot(p1,x1), dot(p2,x2), dot(p3,x3) ) );
  }

  void main() {
      vNormal = normal;
      vPosition = position;
      float displacement = snoise(position * 2.0 + time * 0.5) * 0.2;
      vec3 newPosition = position + normal * displacement;
      gl_Position = projectionMatrix * modelViewMatrix * vec4(newPosition, 1.0);
  }
`;

const fragmentShader = `
  uniform vec3 color;
  uniform vec3 pointLightPosition;
  varying vec3 vNormal;
  varying vec3 vPosition;

  void main() {
      vec3 normal = normalize(vNormal);
      vec3 lightDir = normalize(pointLightPosition - vPosition);
      float diffuse = max(dot(normal, lightDir), 0.0);

      float fresnel = 1.0 - dot(normal, vec3(0.0, 0.0, 1.0));
      fresnel = pow(fresnel, 2.0);

      vec3 finalColor = color * diffuse + color * fresnel * 0.5;

      gl_FragColor = vec4(finalColor, 1.0);
  }
`;

function CameraRig() {
  const { camera, size } = useThree();
  useEffect(() => {
    const aspect = size.width / size.height;
    camera.position.z = aspect < 1 ? 3 + (1 - aspect) * 4 : 3;
    camera.updateProjectionMatrix();
  }, [camera, size]);
  return null;
}

function NoiseIcosahedron() {
  const meshRef = useRef();
  const lightRef = useRef();
  const { camera } = useThree();

  const uniforms = useMemo(() => ({
    time: { value: 0 },
    pointLightPos: { value: new THREE.Vector3(0, 0, 5) },
    color: { value: new THREE.Color("#C8FF00") },
  }), []);

  useFrame((state) => {
    uniforms.time.value = state.clock.elapsedTime * 0.3;
    if (meshRef.current) {
      meshRef.current.rotation.y += 0.0005;
      meshRef.current.rotation.x += 0.0002;
    }
  });

  const handleMouseMove = useCallback((event) => {
    const x = (event.clientX / window.innerWidth) * 2 - 1;
    const y = -(event.clientY / window.innerHeight) * 2 + 1;
    const vec = new THREE.Vector3(x, y, 0.5).unproject(camera);
    const dir = vec.sub(camera.position).normalize();
    const dist = -camera.position.z / dir.z;
    const pos = camera.position.clone().add(dir.multiplyScalar(dist));
    if (lightRef.current) lightRef.current.position.copy(pos);
    uniforms.pointLightPos.value.copy(pos);
  }, [camera, uniforms]);

  useEffect(() => {
    window.addEventListener("mousemove", handleMouseMove);
    return () => window.removeEventListener("mousemove", handleMouseMove);
  }, [handleMouseMove]);

  return (
    <>
      <pointLight ref={lightRef} position={[0, 0, 5]} intensity={1} distance={100} color="#ffffff" />
      <mesh ref={meshRef}>
        <icosahedronGeometry args={[1.2, 64]} />
        <shaderMaterial
          uniforms={uniforms}
          vertexShader={vertexShader}
          fragmentShader={fragmentShader}
          wireframe
        />
      </mesh>
    </>
  );
}
```

```jsx
import React, { Suspense, useEffect, useMemo, useRef } from 'react';
import { Canvas, useFrame } from '@react-three/fiber';
import { Environment, MeshDistortMaterial } from '@react-three/drei';
import WebglErrorBoundary from './WebglErrorBoundary';

function GlassBlob({ reducedMotion, pointerRef }) {
  const meshRef = useRef();

  useFrame((state, delta) => {
    const mesh = meshRef.current;
    if (!mesh) return;

    if (!reducedMotion) {
      mesh.rotation.y += delta * 0.12;
      mesh.rotation.x += delta * 0.04;
    }

    const targetX = pointerRef.current.y * 0.25;
    const targetY = pointerRef.current.x * 0.35;
    mesh.rotation.x += (targetX - mesh.rotation.x) * 0.03;
    mesh.rotation.y += (targetY - mesh.rotation.y) * 0.03;
  });

  return (
    <mesh ref={meshRef}>
      <icosahedronGeometry args={[1.4, 12]} />
      <MeshDistortMaterial
        color="#C8FF00"
        transparent
        opacity={0.16}
        roughness={0.08}
        metalness={0.15}
        distort={reducedMotion ? 0 : 0.28}
        speed={reducedMotion ? 0 : 1.2}
      />
    </mesh>
  );
}

export default function HeroGlassScene() {
  const pointerRef = useRef({ x: 0, y: 0 });
  const reducedMotion = useMemo(
    () =>
      typeof window !== 'undefined' &&
      window.matchMedia('(prefers-reduced-motion: reduce)').matches,
    []
  );

  useEffect(() => {
    if (reducedMotion) return undefined;
    const handlePointerMove = (event) => {
      pointerRef.current.x = (event.clientX / window.innerWidth) * 2 - 1;
      pointerRef.current.y = (event.clientY / window.innerHeight) * 2 - 1;
    };
    window.addEventListener('pointermove', handlePointerMove, { passive: true });
    return () => window.removeEventListener('pointermove', handlePointerMove);
  }, [reducedMotion]);

  return (
    <div className="hero-3d-scene" aria-hidden="true">
      <WebglErrorBoundary fallback={null}>
        <Canvas
          gl={{ antialias: true, alpha: true }}
          camera={{ fov: 42, near: 0.1, far: 100, position: [0, 0, 4.2] }}
        >
          <ambientLight intensity={0.7} />
          <pointLight position={[3, 3, 4]} intensity={1.1} color="#C8FF00" />
          <Suspense fallback={null}>
            <Environment preset="city" />
            <GlassBlob reducedMotion={reducedMotion} pointerRef={pointerRef} />
          </Suspense>
        </Canvas>
      </WebglErrorBoundary>
    </div>
  );
}
```
